# Nahid Molla — Personal Portfolio Website

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript. It is ready to deploy on Vercel or GitHub Pages. No paid domain is required.

## Files
- `index.html` — all website text and page sections
- `style.css` — colors, layout, responsive/mobile design
- `script.js` — mobile navigation and project carousel
- `assets/nahid-profile.jpg` — your uploaded profile photo
- `Nahid-Molla-CV.pdf` — public CV with sensitive ID details omitted

## Publish online free with GitHub + Vercel
1. Sign in or create a free account at https://github.com
2. Click **New repository**. Name it `nahid-molla-portfolio`. Choose **Public**, then **Create repository**.
3. Extract this ZIP on your computer.
4. Open the new GitHub repository and choose **Add file → Upload files**.
5. Upload everything inside the extracted `nahid-molla-portfolio` folder (upload the files and the `assets` folder, not the ZIP itself). Commit the changes.
6. Sign in at https://vercel.com using **Continue with GitHub**.
7. Click **Add New → Project**, import `nahid-molla-portfolio`.
8. Framework preset: **Other**. Build command: leave blank. Output directory: leave blank or use `.`. Click **Deploy**.
9. Vercel gives you a free address such as `nahid-molla-portfolio.vercel.app`. You can edit the website any time by changing files in GitHub; Vercel automatically redeploys.

## Edit the website
- Change name, profile text, phone numbers, services, experience and email in `index.html`.
- Change colors near the top of `style.css`. Main Qatar maroon is `#7b1738`; white is `#ffffff`.
- Replace your photo by uploading a new image named exactly `nahid-profile.jpg` into `assets` (overwrite the old one).
- Replace the sample project cards in the `#work` section of `index.html` with your own project images and descriptions.
- To update the CV, replace `Nahid-Molla-CV.pdf` with your new public CV using the same filename.

## Important privacy note
Your original uploaded CV contains personal identity and passport/QID details. The downloadable CV included here intentionally leaves those details out. Do not publish ID numbers, passport numbers, full date of birth or private home address on a public website.
